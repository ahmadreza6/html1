۱. معرفی سرویس

هدف سرویس

سرویس GetMelatStatements از پروژه گردش حساب‌های بانکی با هدف دریافت گردش حساب بانکی مشتری از سامانهٔ بانک ملت توسعه یافته است. این سرویس با دریافت شماره حساب و تاریخ موردنظر، لیست تراکنش‌های بانکی مرتبط را به‌صورت یکپارچه در اختیار مصرف‌کنندگان سرویس قرار می‌دهد.

از مهم‌ترین اطلاعات قابل دریافت توسط این سرویس می‌توان به موارد زیر اشاره نمود:

  • شناسه گردش حساب بانک
  • شماره حساب بانکی مرتبط
  • مبلغ تراکنش
  • زمان و تاریخ تراکنش (میلادی و شمسی)
  • شناسه پرداخت و کد رهگیری بانک
  • کد شعبه و سریال بانکی
  • توضیحات بانک و نوع تراکنش (واریز / برداشت)
  • نام پرداخت‌کننده و سایر اطلاعات مرتبط

۲. احراز هویت (Authentication)

این وب‌سرویس نیز همانند سایر وب‌سرویس‌های پروژه گردش حساب‌های بانکی از JWT (JSON Web Token) جهت احراز هویت استفاده می‌کند. کلیهٔ درخواست‌ها باید هدر زیر را ارسال نمایند: 

Authorization: Bearer {JWT Token}

در صورت معتبر نبودن Token، سرویس پاسخ مناسب با خطای احراز هویت را باز خواهد گرداند.

۳. آدرس پایه سرویس (Base URL)

https://{Domain}/api/CDP

مقدار Domain در محیط‌های Development، Test و Production متفاوت خواهد بود.

۴. ساختار استاندارد پاسخ سرویس‌ها

این وب‌سرویس خروجی خود را بر اساس کلاس استاندارد Result<T> باز می‌گرداند. ساختار کلی پاسخ به‌صورت زیر است:

پاسخ موفق

{
    "isSuccess": true,
    "data": {
        "transactions": [ ... ]
    },
    "metadata": null,
    "error": null
}

فیلدهای پاسخ:

فیلدتوضیح
isSuccessمشخص‌کنندهٔ موفق یا ناموفق بودن درخواست
dataاطلاعات بازگشتی سرویس (شامل لیست تراکنش‌ها)
metadataاطلاعات تکمیلی مانند نسخهٔ API، صفحه‌بندی و ... (در صورت وجود)
errorدر پاسخ موفق مقدار آن همیشه null است

پاسخ ناموفق

{
    "isSuccess": false,
    "data": null,
    "metadata": null,
    "error": {
        "code": "ACCOUNT_NOT_FOUND",
        "type": "NotFound",
        "message": "Bank account statement not found."
    }
}

در پاسخ‌های ناموفق، اطلاعات خطا در شیء error قرار می‌گیرد.

۵. ساختار Error

ساختار خطا به‌صورت زیر است:

فیلدتوضیح
codeکد یکتای خطا
typeنوع خطا
messageتوضیح خطا

نمونه:

{
    "code": "VALIDATION_ERROR",
    "type": "Validation",
    "message": "AccountNo is required."
}

۶. وب‌سرویس‌های پروژه

در این پروژه، وب‌سرویس‌های دریافت گردش حساب برای بانک‌های زیر ارائه شده است:

  • بانک ملت
  • بانک اقتصاد نوین
  • بانک سامان
  • بانک ملی
  • بانک صادرات
  • بانک سپه

ساختار داده‌های بازگشتی (Data)

مقدار data در پاسخ موفق از نوع MelatStatementConvertSuccessResponse بوده و شامل لیست تراکنش‌های بانکی با ساختار زیر است: 

public class MelatStatementConvertSuccessResponse : IMelatStatementResponse
{
    public List<BankAccountStatement> Transactions { get; set; }
}

فیلدنوعتوضیح
transactionsلیست BankAccountStatementلیست تراکنش‌های گردش حساب بانکی مشتری
